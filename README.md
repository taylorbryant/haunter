# Haunter

Haunter is an open-source application hosted at [haunter.app](https://www.haunter.app).
It keeps notes, tasks, and canvases together, with real-time collaboration and
an MCP API for connected AI agents.

[Open Haunter](https://www.haunter.app) ·
[Read the guides](https://www.haunter.app/guides) ·
[View the changelog](https://www.haunter.app/changelog) ·
[Contribute](CONTRIBUTING.md)

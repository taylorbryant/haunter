Tasks can live inside the notes that explain them or stand on their own. Both appear in the workspace's **Tasks** view, so you can plan in a page and track the work in one place.

## Add a task inside a page

1. Open a page and type `/` where you want the task.
2. Choose **Task** and write what needs to happen.
3. Use the assignment and date controls beside the task to choose a workspace member and a due date.
4. Open **Tasks** in the sidebar to find the same task in the workspace list.

The checkbox in the page and the checkbox in Tasks refer to the same task. Completing it in either place updates the other. Follow the page link beneath a task to return to its surrounding notes. To rewrite the text of a page task, edit it in that page.

## Create a standalone task

Open **Tasks**, choose **Add task**, enter a title, and create it. You can also add a task from Home's Today section.

A standalone task does not need a page. Select its title in Tasks to rename it. Use it for work such as “Book the meeting room”; use a page task when the surrounding notes matter, such as a follow-up from a meeting.

## Assign and schedule work

Use the assignment control to pick a member of the current workspace. A task can also remain unassigned.

Use the date control to choose a calendar date or a preset. Add a time when the task needs one, or leave it as an all-day task.

When creating a standalone task, you can include a phrase such as “tomorrow” or “next Friday” in its title. Haunter highlights the date it recognizes. Check the resulting date before creating the task.

Home shows your overdue work, today's tasks, and tasks coming up in the next seven days. If you expect a task there, check that it is assigned to you and has the intended due date.

## Filter and complete tasks

- **Open** shows work that has not been completed.
- **Completed** shows finished tasks.
- **All** includes both.
- **Mine** limits the list to tasks assigned to you.
- **Everyone** includes the workspace's tasks, including unassigned ones.

![The Tasks view with Open and Everyone selected, showing page tasks linked to This week alongside standalone tasks, with assignees and due dates.](/guides/images/tasks.webp "Page tasks and standalone tasks share one list. Use the filters above it to choose what you see.")

Check a task to complete it. To reopen one, switch to **Completed** or **All**, then clear its checkbox.

If a task seems missing, check the workspace, completion filter, and assignment filter. Tasks belonging to a page in Trash do not appear in the active task list; [restore the page](/guides/saving-and-recovery#restore-a-page-from-trash) to bring it back.

## Plan a week from one page

Create a page called “This week.” Add headings for your projects and task blocks for the next actions. Assign the tasks and set their dates, then use Home for today's work and the page for the broader plan.

With a [connected AI assistant](/guides/ai), you can ask: “Turn the action items on the This week page into tasks and assign them to me.” Include the workspace name if you have more than one page with that title. Review the tasks in the web app after the assistant creates them.

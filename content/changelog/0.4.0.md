## New

- Create a page from anywhere in a workspace using the command palette. Add a title and optional details, then continue editing the new page.
- Press `⌘/Ctrl + Shift + C` to create a page or `⌘/Ctrl + Shift + Enter` to create a task.

## Improved

- Creating a task from the command palette or Tasks now opens a focused dialog without navigating away. Choose an assignee and due date or time before adding it.
- Due-date changes apply when you close the picker, so pressing Done is optional.
- Page and task creation use dialogs on desktop and bottom sheets on mobile.

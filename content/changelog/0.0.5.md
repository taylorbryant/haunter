## New

- Connect an AI agent to search, read, create, update, and organize pages and tasks.
- Review an agent's requested access before approving it, then disconnect the agent from Settings at any time.
- Inspect recent agent activity from the Agents settings panel.

## Improved

- Limit agent access to the workspaces relevant to its task.
- Let an existing agent request additional access without reconnecting from scratch.

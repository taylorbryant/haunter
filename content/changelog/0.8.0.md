## New

- Create a standalone canvas from the Canvases section or command palette, without adding it to a page.
- Browse every standalone canvas in one dedicated workspace view.
- Star important canvases for Favorites and return to recently viewed canvases from Home.
- Rename a canvas from its actions menu or remove it from the Canvases view.

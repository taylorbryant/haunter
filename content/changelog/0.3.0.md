## New

- Connect supported AI clients directly to Haunter through a hosted MCP server, without running a local bridge.
- Sign in with your Haunter account and choose a clear access profile and one or more workspaces.
- Review hosted client activity and disconnect a client immediately from Agents settings.

## Improved

- The guided connection dialog recommends hosted MCP while keeping the local Agent Auth bridge available for compatibility.
- Workspace membership and roles are checked again for every agent action.

## New

- Install Haunter on your phone or computer for an app-like experience.
- Type `>` in Search to open commands for navigation, tasks, workspaces, and settings.
- Add dates to task text with phrases such as `tomorrow` or `next Friday`.
- Open a code block in a focused fullscreen editor.

## Improved

- New task blocks are assigned to you automatically.
- New pages begin ready for you to name and start writing.

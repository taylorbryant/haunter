## New

- Start from Home to see overdue and due-today tasks, the next seven days, favorite pages, and recently viewed pages.
- Favorite important pages from the sidebar or page header.
- Return to recently viewed pages from Search and Home.
- Import and export pages as Markdown, and export themed HTML files.
- Connect Haunter to AI clients through the guided MCP setup.
- Choose from coordinated light and dark app and code themes.

## Improved

- Agent permission profiles make recurring access easier to understand and reuse.
- Task dates, due-date presets, and overdue indicators now follow your device timezone.
- Code blocks have a consistent header and editing experience in fullscreen mode.
- Canvas and page saving are more resilient to concurrent changes.

## Fixed

- Recently viewed pages now update immediately throughout the app.
- Page renaming from the desktop sidebar remains active until you finish editing.
- Mobile navigation and notification controls have more consistent spacing and positioning.

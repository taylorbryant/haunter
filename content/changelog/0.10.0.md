## Haunter in your AI chat

- Open Haunter in clients that support MCP Apps to browse and edit pages, canvases, and tasks alongside your conversation.
- Use Home, favorites, page history, and Trash from the embedded workspace, with a Haunter theme that stays selected when you reopen the panel.
- Select text or canvas shapes in the panel to give your assistant context for its next reply.
- Task and favorite changes made by agents update open embedded views without a manual refresh.

## More capable agents

- Ask connected agents to edit individual page blocks and tables, move content, and attach files.
- Build and revise canvases with groups, frames, alignment, and distribution, and insert library components and images.
- Let agents manage standalone canvases and favorites, follow backlinks, browse Trash, and restore saved page or canvas versions.
- See when an agent is working on a page or canvas, with brief highlights on shapes it creates or updates.

## Search and sharing

- Search page text, tasks, and canvas titles and text from one workspace search, with filters for each type.
- Open a canvas search result at the matching shape, including drawings inside pages.
- Public page links include a preview image with the page title and icon when shared in apps that support link previews.

## Mobile improvements

- Format text from a toolbar above the mobile keyboard, with clearer styling for active formatting controls across themes.
- Shared pages and canvases fit better on small screens, and Trash gives page titles and actions more room.
- Delete a code block from its options menu on mobile.
